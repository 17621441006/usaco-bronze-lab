## Automated verification

QA-only packages are installed outside the project in `/tmp/usaco-dom-tests`; they are not application dependencies.

```sh
npx tsc --noEmit
JSDOM_TEST_DIR=/tmp/usaco-dom-tests/node_modules/jsdom node scripts/verify-ui-v2.cjs
node scripts/verify-completions.cjs
node scripts/verify-shell-editing.cjs

node scripts/verify-scene-framing.cjs
```

The UI DOM regression covers the learning route, both course directories, bilingual classic reading, editor save/run/grade wiring, font/theme/fullscreen controls, tab retention and overflow closing, sample-only restrictions, four-question exam setup, notes, source statistics, Shell retention and the standalone editor. Grid checks cover BFS/DFS steps and fences, a single-cell prefix sum, rectangle intersection/union and a disjoint case. Monaco and WebGL drawing are mocked in that test; actual Python execution is covered separately by worker tests.

Production packaging uses the Sites build helper with the existing Vinext/Cloudflare configuration. TypeScript and build output must pass before publication. No lint rules or hosting requirements are relaxed.
